# User Guide

## Create a Website

1. Open TemplateForge.
2. Select `New Project`.
3. Enter a project name and description.
4. Open the project from the Projects page.
5. Add extra pages if needed.
6. Open a page editor.
7. Add components from the toolbox.
8. Edit component text or images.
9. Edit the theme.
10. Export the static site.

## Components

Hero:

- Main heading
- Short subtitle

Text:

- Body content

Image:

- One uploaded image
- Alt text for accessibility

Gallery:

- Multiple uploaded images
- Shared alt text for newly uploaded images

Footer:

- Footer/copyright text

## Export Result

The exported folder contains static files only. It can be opened locally or uploaded to a static hosting provider.
